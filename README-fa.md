# بازی دزد و کارآگاه — نسخه وب

بازسازی تحت وب بازی C++ شما با HTML، CSS و JavaScript خالص؛ بدون نیاز به نصب کتابخانه یا ابزار ساخت.

## اجرای بازی

1. فایل ZIP را از حالت فشرده خارج کنید.
2. پوشه `thief-detective-web` را در VS Code باز کنید.
3. فایل `index.html` را با Live Server اجرا کنید. باز کردن مستقیم فایل در مرورگر هم معمولاً کار می‌کند، اما برای ذخیره پایدار تنظیمات و رکوردها، Live Server مطمئن‌تر است.

## ساختار پروژه

```text
thief-detective-web/
├── index.html              # ساختار صفحات و رابط کاربری
├── styles.css              # طراحی، واکنش‌گرایی و انیمیشن‌های ظاهری
├── game-core.js            # قوانین خالص بازی؛ جدا از DOM و قابل‌آزمایش
├── game.js                 # رابط، کنترل‌ها، انیمیشن و ذخیره‌سازی
├── assets/
│   └── logo.png            # لوگوی بازی
└── tests/
    ├── game-core.test.js  # تست‌های خودکار منطق بازی
    └── ui-structure.test.js # تست‌های ساختار و دسترس‌پذیری رابط
```

## قابلیت‌ها

- صفحه بارگذاری اولیه با انتظار برای آماده‌شدن لوگو و فونت (با زمان نمایش حداقلی ۳٫۱ ثانیه).
- منوی اصلی، راهنما، تنظیمات، رکوردها و پنجره پایان بازی.
- نقشه ۱۰ خانه‌ای و سه مهره اجرایی `T`، `t` و `D`.
- حرکت شبکه‌ای L شکل: عمودی، افقی در امتداد خیابان و عمودی به داخل خانه مقصد.
- کارآگاه نیز مانند دو مهره دیگر وارد خانه مقصد می‌شود؛ این یک تصمیم طراحی نسخه وب است.
- انیمیشن حرکت فقط خود مهره را جابه‌جا می‌کند؛ مسیر، خط نورانی یا trail جداگانه رسم نمی‌شود.
- سرعت انیمیشن: سریع ۲٫۵ ثانیه، معمولی ۵ ثانیه، آرام ۷٫۵ ثانیه.
- گزینه مستقل «کاهش حرکت‌های بصری» مدت انیمیشن را به حداکثر ۳۵۰ میلی‌ثانیه کاهش می‌دهد.
- تنظیمات صدا، سرعت و کاهش حرکت در مرورگر ذخیره می‌شوند.
- سه رکورد برتر، تعداد بازی‌ها، میانگین امتیاز و بهترین امتیاز ذخیره می‌شوند.
- چیدمان واکنش‌گرا برای دسکتاپ، تبلت و موبایل.

## بهبودهای تجربه کاربری در این نسخه

- راهنمای سه‌مرحله‌ای در اولین اجرای بازی؛ هدف، روش حرکت و نقش کارآگاه را توضیح می‌دهد و امکان رد کردن دارد.
- راهنمای ثابت هر نوبت، مرحله فعال را مشخص می‌کند: انتخاب مهره، انتخاب خانه و حرکت کارآگاه.
- خانه‌های خالی پیش از انتخاب مهره هم قابل تعامل‌اند تا بازی به‌جای بی‌واکنش بودن، کاربر را به مرحله درست راهنمایی کند.
- خانه‌های قابل انتخاب، اشغال‌شده و در انتظار انتخاب مهره با وضعیت بصری و متن جایگزین متفاوت مشخص می‌شوند.
- بخش «پیش‌بینی حرکت کارآگاه» توضیح می‌دهد درصدها چه معنایی دارند؛ در نمایشگرهای کوچک، جزئیات احتمال‌ها به‌صورت جمع‌شونده نمایش داده می‌شود. پس از محاسبه تصمیم کارآگاه، احتمال‌های اصلاح‌شده نیز در همان بخش نمایش داده می‌شوند.
- پیام‌های راهنمای لحظه‌ای پس از انتخاب مهره، انتخاب خانه، رد کردن حرکت و حرکت کارآگاه به‌روزرسانی می‌شوند.
- چشم مراقب در زمان فعال‌شدن به‌صورت یک نشان متحرک در امتداد خیابان دیده می‌شود؛ سمت نشان و متن آن، زوج یا فرد بودن خانه‌های تحت نظر را مشخص می‌کند.
- احتمال ظاهرشدن چشم پس از هر بار غیبت ۲۰ واحد درصد افزایش می‌یابد و پس از ظاهرشدن به صفر برمی‌گردد؛ مقدار احتمال نوبت بعد نیز نمایش داده می‌شود.
- اثر چشم روی گزینه‌های کارآگاه پس از انتخاب مقصد محاسبه و در لحظه نمایش داده می‌شود: یا دزد اصلی با احتمال ۱۰۰٪ هدف قرار می‌گیرد، یا گزینه‌های هم‌الگو حذف و وزن گزینه‌های باقی‌مانده دوباره توزیع می‌شود.
- صفحه پایان بازی علاوه بر امتیاز، تعداد حرکت‌های کارآگاه، بهترین امتیاز و تعداد بازی‌ها را نشان می‌دهد.
- برای کنترل با صفحه‌کلید، حالت فوکوس واضح و برای تنظیمات سیستم‌عامل، کاهش حرکت بصری در نظر گرفته شده است.

## منطق بازی و تفاوت‌های آگاهانه با C++

- شمارنده‌های نوبت، تعداد گزینه‌های کارآگاه، آستانه‌های احتمالات و شرط پایان بازی در `game-core.js` از منطق اجرایی فایل C++ استخراج شده‌اند.
- برای انتخاب گزینه‌های جایگزین، الگوریتم Fisher–Yates جایگزین `sort(() => Math.random() - 0.5)` شده است تا مخلوط‌کردن آرایه منصفانه‌تر باشد.
- اثر چشم دوم با حذف حداکثر دو خانه هم‌زوج یا هم‌فرد از فهرست فعال بازسازی شده است؛ این پیاده‌سازی، برداشت امن و قابل‌پیش‌بینی از منطق swap/decrement در کد C++ است. تصمیم نهایی و درصدهای نمایشی از یک مجموعه گزینه اصلاح‌شده مشترک استفاده می‌کنند تا احتمال نشان‌داده‌شده با انتخاب واقعی کارآگاه هماهنگ باشد.
- رد کردن حرکت در رابط وب معادل ورودی `10` در کد C++ است و همچنان در محاسبه اثر نشانه ویژه شرکت می‌کند.
- در نسخه C++ کارآگاه در خیابان و کنار خانه مقصد می‌ایستاد؛ بنا به درخواست شما در نسخه وب به داخل خانه مقصد می‌رود و پایان بازی هنگامی است که خانه کارآگاه و دزد اصلی یکی شود.
- نقش نگهبان در متن راهنمای C++ نام برده شده بود، اما در کد اجرایی ارسال‌شده منطق حرکتی مستقلی برای آن وجود نداشت؛ بنابراین سه مهره اجرایی در نسخه وب وجود دارد.

## ذخیره‌سازی

داده‌ها در `localStorage` همان مرورگر و همان پروفایل ذخیره می‌شوند. اگر مرورگر دسترسی به ذخیره‌سازی را مسدود کند، بازی همچنان اجرا می‌شود اما رکوردها و تنظیمات ممکن است پس از بستن صفحه باقی نمانند.

## اجرای تست‌های منطق

برای اجرای تست‌ها، Node.js را نصب کنید و در ترمینال پوشه پروژه اجرا کنید:

```bash
node --test tests/*.test.js
```

تست‌ها منطق اصلی بازی (مخلوط‌کردن خانه‌ها، شمار گزینه‌های احتمالی، اثر نشانه ویژه، انتخاب وزن‌دار، شمارنده‌های نوبت و شرط پایان بازی) و ساختار رابط (یکتایی شناسه‌ها، وجود selectorهای استفاده‌شده، دسترس‌پذیری راهنماها و وضعیت فوکوس) را بررسی می‌کنند.

## ویرایش سرعت‌ها

مدت انیمیشن‌ها در ابتدای `game.js` و در ثابت `ANIMATION_DURATIONS` تعریف شده‌اند. مقادیر فعلی بر حسب میلی‌ثانیه هستند:

```javascript
const ANIMATION_DURATIONS = {
  fast: 2500,
  normal: 5000,
  slow: 7500
};
```


## بازخورد بصری تصمیم کارآگاه

پس از حرکت بازیکن، اگر چشم احتمال‌ها را تغییر دهد، نوارهای احتمال به‌صورت متحرک از مقدار قبلی به مقدار جدید می‌رسند؛ اعداد نیز شمارش می‌شوند و گزینه‌های حذف‌شده برای لحظه‌ای با برچسب «حذف‌شده» باقی می‌مانند. سپس خانه‌ای که کارآگاه واقعاً با انتخاب وزن‌دار برگزیده است، پیش از حرکت با کادر آبی و کارت «مقصد کارآگاه» مشخص می‌شود. پس از مکث کوتاه، انیمیشن حرکت کارآگاه آغاز خواهد شد.
